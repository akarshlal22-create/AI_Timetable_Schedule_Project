# Screenshots Directory

This directory contains visual artifacts and screenshots of the Streamlit application for documentation and report preparation.

## Expected Screenshots

1. **`data_tab.png`**: View of the **Data** tab showing a loaded problem summary (e.g. `small.json` or `large.json`) and an inspected entity table (`Subjects`, `Classes`, `Rooms`, or `Teachers`).
2. **`generate_result.png`**: View of the **Generate** tab displaying the single-row execution summary (Algorithm status, Time taken, Nodes/Iterations, Hard violations, Soft penalty, Total cost) and the Cost vs. Iterations convergence chart.
3. **`class_grid.png`**: View of the **Timetable** tab showing the full-width weekly schedule grid by Class (e.g., `CS-A`), featuring muted lunch and break periods and 2-period lab continuation markings.
4. **`conflict_highlighted.png`**: View of the **Timetable** tab under **Edit Session**, demonstrating an intentional clash (e.g., placing a lab into a classroom or double-booking a teacher) with the live conflict warning and red-highlighted cells in the grid.
5. **`experiment_graph.png`**: Benchmark comparison graph generated by `python -m experiments.run_all` (e.g., runtime comparison or hybrid refinement).

## How to capture screenshots
1. Launch the application: `streamlit run app.py`
2. Open your web browser at `http://localhost:8501`.
3. Capture each view listed above and save the image into this directory using the corresponding filename.
